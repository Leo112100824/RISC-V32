# RV32I 工程总览

本仓库实现一个以 FPGA 同步指令 BRAM 为目标的 RV32I + Zicsr 五级流水线核。活动 RTL 位于 rtl/core/；rtl/legacy/ 是已归档的单周期和旧流水线实现，不参加当前编译。

## 当前状态

- RV32I 41 条基础指令、Zicsr 6 条 CSR 指令，以及 MRET 已实现。
- 流水线为 IF → ID → EX → MEM → WB，带前递、load/CSR-use 停顿和精确异常处理。
- 定向整核程序检查 89 个结果、8 类 trap。
- 16 个活动 RTL 模块各有一个独立 testbench；core/top 另有两段流水线程序测试。
- 当前完整回归通过情况和详细技术债以 make regression-check 结果及[工程状态与路线](已完成功能与完善方向.md)为准。官方 riscv-tests、外部中断投递、随机/Spike 差分仍待完成。

## 目录约定

- rtl/core/：当前活动 RTL。
- rtl/legacy/：保留的旧版 RTL 和其历史说明。
- model_tb/program/：测试程序生成器及其生成的 HEX/期望值文件。修改生成器，不要手工编辑生成结果。
- model_tb/unit/：每个活动模块独立的 SystemVerilog testbench。
- scripts/：回归运行器和运行器自身的负向测试。
- model_tb/results/：仿真日志与 JSON 汇总，自动生成且由 Git 忽略。

## 执行环境

需要 Python 3.10+、GNU Make 和 QuestaSim 2024.1（当前验证版本）的 vlib、vlog、vsim。命令从上层工作区、Git 仓库根目录或 model_tb/ 调用均可；克隆后直接在仓库根目录运行。详细命令见[测试运行指南](测试运行与故障排查.md)。
