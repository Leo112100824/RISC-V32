# 工程状态与后续路线

更新时间：2026-10-23。这里记录实际实现和已执行验证，定向通过不等于官方兼容性验收。接口见[架构总览](architecture.md)，操作见[测试运行指南](测试运行与故障排查.md)。

## 当前交付

| 内容 | 已实现范围 |
|---|---|
| 指令 | RV32I 41 条、Zicsr 6 条；另有 MRET。FENCE 为当前无 Cache 顺序模型的空操作，FENCE.I 通过 redirect 冲刷流水线 |
| 流水线 | IF1/IF2/ID/EX/MEM/WB，head/tail 取指队列，每级有效位 |
| 数据冒险 | EX/MEM、MEM/WB 前递，EX/MEM 优先；load/CSR-use 停顿、寄存器堆写优先旁路 |
| 控制冒险 | EX 解析分支/JAL/JALR/MRET/FENCE.I；flush 优先于 stall |
| CSR | 14 个 Machine CSR，含 64 位 mcycle/minstret 高低半字 |
| 同步异常 | 非法指令、ECALL、EBREAK、指令/load/store 非对齐、CSR 只读/未实现；较老 MEM 异常优先于 EX |
| trap/MRET | direct mtvec、mepc/mcause/mtval、MIE/MPIE/MPP 更新；同拍 mepc/mtvec CSR 写旁路 |
| 存储器 | 指令同步读一拍，数据组合读/同步字节写；没有数据侧 ready/等待握手 |

## 最近验证基线

以下是 2026-10-23 在 QuestaSim 2024.1 上实际执行的结果。修改代码后应重新运行。

| 验证 | 基线结果 | 证明范围 |
|---|---|---|
| 17 个独立模块 bench | 17/17，174 项计数检查 | 已列明的定向边界和阶段组合行为 |
| 原有 tb_top | 89 个结果、8 次 trap；380 个指令字 | RV32I/Zicsr 指令定向程序、异常返回 |
| core/top 附加程序 | 各两段、18 项检查；44/31 周期到签名 | RAW、load/CSR-use、错误路径抑制、MRET、实际 MEM/EX 异常重叠优先级 |
| 回归器自测 | 7/7 | 错误退出、缺少/伪造完成标记、Fatal/Error、超时 |

174 是 bench 主动统计的检查数，不是覆盖率百分比；core/top 分别运行相同两段程序验证各自 DUT。44/31 是特定程序到签名的周期数，不是通用 CPI。

回归器编译一次后顺序仿真，检查退出码、错误消息及完成标记。日志和 JSON 汇总放在 model_tb/results/。完整模块映射见[单元测试清单](../model_tb/unit/README.md)。

## 本轮修复

- IF2 去重只比较有效表项，避免空 tail 的初始 PC=0 阻止首条指令入队。
- stall 时禁止把重复 head 返回再放入 tail，避免指令重放。
- 加强 IF2/CSR/EX/MEM 测试，补真实程序、MEM/EX 同拍异常检查。
- 整核失败使用 $fatal，统一回归器严格返回失败，避免只打印失败却被脚本视作成功。

## 后续路线与限制

| 优先级 | 任务 | 验收目标/限制 |
|---|---|---|
| P0 | 官方 riscv-tests | 先 rv32ui，再评估当前 M 模式能力支持的 rv32mi；M 扩展前不能宣称 rv32um 通过 |
| P0（SoC 前） | 数据侧握手 | 增加 MEM 等待/回压，支持同步 BRAM/总线 |
| P1 | 外部/定时器中断 | mie/mip 目前仅存储；补 pending/使能、精确 mepc、MRET 检查 |
| P1 | 验证与性能 | CPI/停顿统计、随机指令、断言、覆盖率报告 |
| P1 | M 扩展 | 独立 muldiv、乘除边界与 busy/stall，然后跑 rv32um |
| 后续 | Spike、UVM、SoC、FPGA | 总线/外设、UART/Timer/GPIO、时序资源报告 |

尚无 U/S 模式、Cache、完整总线、PLIC、板级约束。misa 写忽略，mtvec 仅按 direct 基址使用。图只作参考，最新功能以 RTL 和本文为准。
